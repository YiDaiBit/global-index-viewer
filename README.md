# 全球指数查看器

在 macOS 上本地查看全球主要股指、商品、利率汇率和加密资产的公开行情。

## 隐私

- 不注册、不登录、不设用户系统
- 不采集姓名、账号、持仓、设备标识或其他个人信息
- 不使用第三方统计、广告或字体服务
- 搜索只在本地过滤指数列表，不会把输入发到外部
- 开发服务器只监听 `127.0.0.1`，仅本机可访问
- 本机只会向公开行情源请求市场指数数据

## 在 macOS 上运行

需要已安装 [Node.js 18+](https://nodejs.org/)。

```bash
cd 全球指数查看器
npm install
npm run dev
```

浏览器会打开 `http://127.0.0.1:5173`。也可以双击 `启动.command`。

## 功能

- 美洲、欧洲、亚太主要股指
- 黄金、原油等大宗商品
- 美元指数与美债收益率
- 比特币、以太坊
- 分类浏览、本地搜索、分时/日线走势
- 主要市场开收盘状态

行情可能延迟，仅供浏览，不构成投资建议。
